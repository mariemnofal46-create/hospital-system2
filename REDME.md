#  Hospital Management System

A simple web project built using HTML, CSS, and JavaScript.

##  Features
- Add patient data (Name, Age, Phone, Disease)
- Display patients in beautiful cards
- Delete patient
- Search for patient by name
- Save data in browser (Local Storage)

##  Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the website
2. Enter patient details
3. Click "Add Patient"
4. View and manage patients easily
